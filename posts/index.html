健身日志与计划表

篮球专项力量提升训练计划（每周三练 + 每周两次轻有氧）

适用：不以冲击 1RM/比赛为目标，追求稳步提升力量与对篮球动作转化；每次训练 60–90 分钟。

一、每周安排（建议）

  • 周一 A：深蹲 + 实力推（基础力量）
  • 周二：轻松跑 3–5km 或 1km 游泳（轻松区间）
  • 周三 B：罗马尼亚硬拉（RDL）+ 负重引体（后侧链与上肢拉）
  • 周四：轻松跑 3–5km 或 1km 游泳（轻松区间）
  • 周五 C：卧推 + 速度深蹲/前蹲（转化与爆发）
  • 周六：攀岩
  • 周日：休息/拉伸/散步

二、强度与进阶规则（稳步提升）

  1. 主项采用“次数区间 + RPE”控制：大多数训练保持 RPE 7–9（还剩 1–3 次余量），不追极限。
  2. 双进阶包含两条。主项给次数区间（如 4–6 次/组），当同一重量所有组都做到上限且动作干净（例如 5×6）→ 下次加重量（上肢 +2.5kg；下肢 +5kg）。辅助动作给 6–10 或 8–12 次区间，做到上限再小幅加重。
  3. 每 4 周做 1 次减量周：训练量减少 30–40%（组数减少），强度保持中等（RPE 6–7），帮助恢复并为下一轮进步做准备。

三、每次训练时间结构（60–90 分钟）

  • 热身 10–12 分钟
  • 主项 1：20–25 分钟（组间休息 2–4 分钟）
  • 主项 2：15–20 分钟（组间休息 2–4 分钟）
  • 辅助 2–3 个：20–25 分钟（组间休息 60–120 秒）
  • 核心 8–12 分钟

四、训练日详细计划（每次：下肢 + 上肢）

A 日：深蹲 + 实力推（基础力量）

  • 深蹲：5×4–6（RPE 7–8）
  • 实力推/肩推：5×4–6（RPE 7–8）
  • 保加利亚分腿蹲：3×6–10/侧
  • 腿后侧（腿弯举/北欧下放）：3×8–12（北欧 3×3–6）
  • 肩胛健康（面拉/下斜方）：2–3×12–20
  • 核心：腹轮 3×6–12 + 死虫 2×10/侧

B 日：RDL + 负重引体（后侧链与上肢拉）

  • 罗马尼亚硬拉（RDL）：5×5–7（离心 2–3 秒，RPE 7–8；不触地反弹）
  • 负重引体向上：5×3–6（RPE 7–9）
  • 划船（胸托/杠铃划船）：3×6–10
  • 臀/腘补强（髋推/臀桥 或 腘绳肌弯举）：3×8–12
  • 肩胛稳定（面拉/反向飞鸟）：2–3×12–20
  • 核心：侧桥 3×30–45 秒/侧 + Pallof 抗旋转 3×10–12/侧

C 日：卧推 + 速度深蹲/前蹲（转化与爆发）

  • 卧推：5×4–6（RPE 7–8）
  • 速度深蹲（暂停蹲/箱蹲更推荐）：8×2 @ 60–70%（每组都要快、干净；休 60–90 秒）。如果不想做速度：改为前蹲 4×4–6（RPE 7–8）
  • 负重双杠臂屈伸：3×5–10
  • 跳/弹（可选，膝盖状态好才做）：箱跳/原地纵跳 3×3
  • 髋稳定（怪兽走/蚌式）：2–3 组
  • 核心：悬垂举腿 3×6–12 + 反向卷腹 2×10–15

五、热身模板（10 分钟）

  • 动态：髋/踝活动 + 胸椎旋转（各 1–2 分钟）
  • 激活：臀桥 2×10、弹力带侧走 2×10/侧、肩胛下压 2×8
  • 主项逐级热身 4–6 组（逐渐加重，最后一组接近工作重量即可）

六、有氧与篮球兼容建议

  • 有氧保持轻松区（能讲话的配速/强度），避免每次跑到“喘爆”。
  • 球局前 24 小时尽量避免：深蹲高量、单腿大重量、北欧下放大量。
  • 若感觉下肢恢复变差：把一次跑步改为轻松游泳或 20–30 分钟低强度骑行/快走。

七、4 周小周期（循环执行）

  • 第 1 周：建立（RPE 7，找准重量与动作）
  • 第 2 周：加量（同重量每组 +1 次，或主项多 1 组）
  • 第 3 周：加重（达到次数上限且动作干净 → 上肢 +2.5kg / 下肢 +5kg）
  • 第 4 周：减量（主项少 2 组；辅助少 1 项或组数减半；RPE 6–7）

备注：如遇疲劳/睡眠不足/球量增大，优先保留主项与核心，辅助动作可减少 1–2 项。

9个月学习总目标

  • 目标岗位：机器人 RL 运动控制工程师（主线）
  • 差异化方向：四足移动操作 + VLA（支线，仿真为主）
  • 周期：36周，按两周一个周期，共18个周期
  • 产出标准（每周期）：1个可运行代码产出 + 1份指标图表/结果表 + 1份复盘

整合逻辑（为什么这样排）

  • 主线（70%精力）：RL locomotion，直接对应你要投递的运动控制岗位。
  • 支线（30%精力）：VLA quadruped manipulation，用于做“系统能力”与“项目差异化”。
  • 前4个月（周期1-8）：两条线都做细，快速形成可展示项目。
  • 后5个月（周期9-18）：主线继续深挖工程落地，支线做鲁棒性与包装，服务投递和面试。

六、git reset：回滚代码

git reset 用于把当前分支回退到某个提交，并根据参数决定是否保留工作区/暂存区改动。

常用场景：

  • 提交写错了，想重新整理提交内容：用 --soft。
  • 只想撤销提交、保留本地改动：用 --mixed（默认）。
  • 想彻底丢弃最近改动：用 --hard（不可逆，谨慎）。

提示：

  • 回退到指定提交：git reset --hard <commit_id>。
  • 如果提交已经推到远端，回滚需谨慎，建议用 git revert 生成反向提交。

与 git revert 的对比

git revert 不会改写历史，而是创建一个“反向提交”来撤销某次提交的效果，适合已推送到远端的场景。

简要对比：

  • git reset：移动分支指针，可能改写历史；更适合本地或未推送的提交。
  • git revert：新增反向提交，保留历史；更适合已推送的提交。

七、.gitignore 的用法与格式

.gitignore 用来告诉 Git 哪些文件/目录不需要纳入版本控制。常见场景是忽略构建产物、依赖目录、临时文件、日志等。

  • * 匹配任意字符，? 匹配单个字符
  • ** 可跨目录匹配
  • 以 ! 开头表示“取消忽略”

  • source/<page>/index.md：独立页面（如 /checkin/、/roadmap/）

说明：

  • 你可以在 source/_posts/ 下再建很多子目录（例如 weekly/）方便管理。
  • 但“网站栏目分类”主要由文章 front-matter 的 categories 决定，不是由文件夹名决定。

2）path 是“导航跳转地址”，不是“文件分类规则”

在 fengye 里，nav.path 的作用是：点击菜单后跳到哪个 URL。

  • 例如 /posts/、/archives/、/categories/、/checkin/

3）index.md 是目录对应页面的入口文件

规则：

  • source/checkin/index.md -> /checkin/
  • source/roadmap/index.md -> /roadmap/
  • source/about/index.md -> /about/

十二、常见问题排查

  • 页面没更新：确认 hexo g -d 成功后，等待几分钟再刷新。
  • 部署失败：检查 deploy.repo、SSH 权限、仓库地址是否正确。

  • 本地能看线上 404：检查 GitHub Pages 分支是否指向部署分支。
